# ADR 0003 — Astroid component-primitive DX: typed `.astro` props

- **Status:** Moved (2026-09-01)
- **Now lives at:** [bowenlabs/astroidjs → docs/adr/0003](https://github.com/bowenlabs/astroidjs/blob/main/docs/adr/0003-astroid-component-primitive-dx.md)

This ADR governs `packages/astroid`, which moved to its own repository (#327).
The decision still holds and the primitives still work as described — only the
address changed.

**This file is a tombstone, kept on purpose.** ADRs 0005 and 0010 cite "ADR 0003"
by number, and so does the astroid record itself. Deleting the file would leave
those citations pointing at nothing, with no error anywhere to notice it. The
number therefore stays reserved here and is not reused.

Astroid keeps the same numbering rather than restarting, so a new decision in
either repository takes the next number free in **both**. See the
[index there](https://github.com/bowenlabs/astroidjs/blob/main/docs/adr/README.md).
